## Under the Coverslip

An evolution game under a microscope. Start as a single cell, eat algae, divide, and spend DNA to evolve. Every rival in the dish evolves too, by mutation and selection.

The game lives in `docs/`:

- `docs/index.html` is the whole game in one file. Open it in any browser, online or offline.
- `docs/sw.js` and `docs/manifest.webmanifest` let it install to a phone's home screen and run offline when the folder is served over HTTPS (for example with GitHub Pages, source set to the `docs` folder).
